# 未采样候选的目标均值排序与抽样竞争

本轮冻结来源模型、搜索、终端、预算及数值精度。复用Stage68的24个d1000几何、三组保存流和全部9臂结果；目标分数仅分析已有FULL／AFTER／POINT三个角色，不补其他后端的后验。原流与两新流分别报告，统计单位仍是几何，沿用原确认结果与费用。

每个几何为一个scheduler item，依次读三流各9次保存选择。Stage68物理ID、首次同历史同池分歧和实际终验直接复用。保持每次实际抽样风险资格集合，比较其中目标均值首选与实际目标抽样首选；记录目标抽样残差、相对差值、排名、观测状态、动态／共享／初始来源及重复查询。无抽样可行候选时原规则按风险兜底，目标排序诊断记为不适用。

跨流追踪集合固定为同几何全部9臂的实际自适应查询与获证部署物理策略并集。它只提供已发生路径的关注点，不能代表整个候选空间。目标候选的详细对比连接实际查询赢家及本流AFTER部署点；仅用已有缓存真值分类“均值已错／抽样翻转／抽样修复／均值和抽样均对”，未知标签保留未知。4009重点查看同一动态策略的三流轨迹；4023风险排除作为不同机制保留，全部任务的平负例与重复查询均入汇总。不同历史、不同流不作后验因果替换，不推演替代轨迹或证书。

来源作为第25个独立item，复用Stage58的3档案×4折×2来源家族，共24组、96臂案例、192份prefix10／13预测。使用原未用评分重复与原风险资格定义；全四后端、失败、ESS提示保留。Stage61已有一般MSE与raw比较直接引用；本轮新增重点是各臂合格池的均值首选／次选间隔，以及AFTER／POINT、FULL／AFTER和AFTER／native在共同合格池中的未观测排序。近差值沿原描述性分组，不选新阈值；先组内汇总，再按家族描述，重叠档案／折／策略对不当独立任务。

目标风险资格来自保存抽样margin；来源资格来自原保存预测的终端规则，两者分别报告。来源评分是少量重复的经验标签，不是安全证书；来源没有保存联合目标抽样或跨策略协方差，不用边际方差拼造差值后验或抽样结论。观察到某个目标损失不能据此选择均值替换、温度、权重或风险补丁；只有来源支持共同机制时才提出一项最小修正，否则保留模型并明确证据不足。

所有实质分析通过scheduler派往node001–node006，vram0、BLAS单线程；24目标item加1来源item，全部收束后单CPU汇总。仿真、终验、真值函数、拟合、模型／后验恢复、raw条件化与RNG均为0；CPU、尝试和历史费用单列，不冲销。局部替身检查只检验均值／抽样错序分类、空合格池和共同资格集合的接线；大表、向量和历史raw留服务器，仅拉取汇总及焦点字段。
