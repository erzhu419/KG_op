# 四项结构统一候选 U1：本地实现与重放

`representation/orthogonal_function_prior.py` 将正交、组稀疏、二阶分解和低频收缩接入同一个三头函数先验，复用现有公共字典、GPR、来源/通用先验混合和验证效用 KG。冻结 M1 与既有实验身份保持原状。

正交参考为公开来源与候选坐标的边际乘积分布。组内导数能量特征分解构造谱基，来源边际似然学习36个组尺度及谱指数；允许尺度为零，另保留1%弱尾部。目标非截距均值为零，付费观测更新两个后验及混合权重。模型余项与环境 log variance 分开。谱指数范围预设为[0,4]，零值允许来源证据撤回低频偏好。

已有 Inventory 开发来源记录和全部八条旧结构臂目标路径用于重放。两臂读取相同已付费标签；目标真值、独立确认块、模拟器及验证器均未使用。source/full 对照共享正交字典、截距与模型余项，只改变组尺度、谱结构及其混合。

三头平均对数预测密度亦改善；来源拟合全部收敛。36组中f/g/eta分别保留5/4/8个非零额外尺度。乘积参考Gram误差7.08e−11，真实联合坐标Gram误差2.73，说明实际轨迹相关性仍然存在。g和eta谱指数达到预设上界4，本阶段未据此改范围。

两臂在8点与24点后的推荐均相同；下一次KG探针分别在5/8和6/8任务改变。这里没有新的执行路径或部署收益。风险头改善很小，g观测噪声仍按保存的样本方差处理，eta仍为Gaussian log-chi-square近似，尚未修复选中候选风险失准，也未恢复物理风险因子。

五项测试通过，分别检查乘积正交与实际相关性的区别、未见坐标上的字典空间等价、常数坐标、谱梯度，以及相同付费数据下来源信息确实改变后验和KG。单线程重放约4.5 CPU秒；新增来源、目标与验证调用均为零。
