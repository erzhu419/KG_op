# 冻结24几何的两组观测种子复验

沿用[Stage65确认](mainline_terminal_two_comparison_confirmation_results_20261017.md)及[Stage66归因](mainline_confirmation_attribution_results_20261017.md)的模型、任务与决策规则。检验初始化传播的动态策略收益、第三点终端增量能否经受新观测噪声；这是已知几何上的噪声复验，不是新几何确认或模型选择。

固定三家族各8个几何4001–4024（均带202610前缀）、d1000、来源模型、优化器seed、initial10物理策略、64共享邻居、动态候选生成规则及initial10＋3次查询。AFTER、FULL、POINT、OLD、同源GP、STRUCT、STOP及两个native交叉参照，共9臂、7条搜索历史。新观测可以改变自适应候选和抽样消耗，固定优化器seed不表示每个策略的后续TS创新完全一致。

两组观测seed分别为2026105101–5124、2026106101–6124，终验seed分别为2026105201–5224、2026106201–6224，与原4101–4124／4201–4224分离。每组独立初始化观测，同组各臂共享这10条新观测；不复用原证书或跨流raw。两个独立child计划保留相同task seed，输出目录分开，复用现有执行器。

每条新搜索历史同时接原终端与三点两比较终端，名单完全相同。旧安全80／128／128及一次8＋8比较，新安全80／120／120及至多两次8＋8比较；比较delta沿用原0.05/3和新0.05/6，block映射不变。每套终验上限352，online总上限365、STOP362。每组物理目标调用保守上限80,160，两组合计160,320；其中共享初始化480、在线搜索864，双终端并集上限158,976。两套历史尾样本与失败费用不冲销，同上限不宣称同实际用量。来源拟合与来源仿真为0，解析真值另记。

全局顺序为两组初始化→两组候选银行→两组全部在线搜索→两组双终端输入冻结→两组旧终验→两组新终验封存→评分。所有科学计算由scheduler派往node001–node006，CPU批次使用实时空闲物理核和单线程BLAS。全部终验封存后才读取Stage65确定性真值缓存，并按相同几何与物理策略复用；只补缺失策略的解析真值。缓存不得用于搜索、筛选或终端决定。

主比较继续报告AFTER新−旧的真实获证C和带符号G；次级报告AFTER−POINT、FULL−AFTER在两套终端下的差及其变化，保留全部9臂。G=C×（部署质量−最优真实可行initial10质量），4006初始基线仍未定义；全24的G均值不填零，明确条件分母。每组分别列全任务结果，再对同一几何两组效果平均，以24几何为统计单位给描述性配对区间。缺一组时该几何的两组均值保持缺失。原观测流单独参照，不并入新两组的主估计。

预先分列initial／共享邻居／动态策略的带符号质量与获证贡献，第三点挑战与安全样本／门槛前置变化，家族方向、胜平负、假获证、缺失、失败和实际费用。报告最大单几何正贡献比例与去掉该几何的描述性敏感性，完整批次仍是主结果。动态策略身份以物理向量及本任务初始化／共享邻居匹配，不跨臂混用history标签。
