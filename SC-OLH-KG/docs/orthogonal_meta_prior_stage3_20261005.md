# 原始收费函数接入统一表示：预测改善，早期决策缺口仍在

已在72维组正交字典中嵌入四个公开原始收费函数，来源数据联合选择支持与余项。原始线性量先保留，再做组内正交及物理坐标导数谱变换；它们是单位标准化导数能量的单变量函数。保留来源非截距系数的完整二阶矩，非截距目标均值仍为零；eta先验、联合批次更新及相关KG不变。贪心支持的内层留一已改为只在该折训练来源上重选。旧M1和既有结果保持原身份。

转换测试覆盖乘积边际正交性、原始收费量保留、新坐标上的Gaussian函数协方差及付费后验等价性、内层来源排除；加上既有正交与联合更新测试，共12项通过。实际公开几何的乘积Gram误差5.58e−11；相关轨迹联合Gram误差2.73，二者不是同一个正交定义。来源与重放共26.3 CPU秒，追加来源几何诊断12.4 CPU秒；无服务器派单、新episode或验证。

8个外层来源留一中，f/g全部选择四个收费量和零余项。f标签RMSE由U1的0.21836降到0.04113，g由0.13086降到0.08272；工作Gaussian预测log density分别由0.143/0.530升到1.758/1.045。来源学出的零余项明显优于强制0.02，不能根据目标负结果事后将0.02称为已学出的最优值。

相同目标付费前缀上，联合预测log score由U1的0.01299升到0.36937，g RMSE由0.11755降到0.10151，eta几乎不变。推荐固定后再对已打开开发规律解析评分：

| 平均真实预计验证收益 | 8点 | 24点 |
|---|---:|---:|
| 旧U1联合更新 | 0.74850 | 0.86018 |
| 收费支持、来源所选零余项 | 0.67645 | 0.86174 |
| 相同支持、强制余项0.02 | 0.74951 | 0.86010 |
| 同来源72维汇总尺度控制 | 0.74958 | 0.86273 |

汇总控制与收费支持采用相同eta混合，隔离均值结构。新支持相对U1在8点后为1胜5平2负，平均−0.07205；24点后为4胜2平2负，平均+0.00156。相对同字典控制最终−0.00099，开发任务配对bootstrap区间[−0.00272,0.00024]。这些结果未建立新的少目标观测决策优势。

两个最大早期校准误差均发生在已有付费观测的候选。95431/33预测通过率0.90988，实际5.02e−21；g偏差−3.22个后验标准差，eta偏差−0.53。95425/18预测0.92882，实际0.34105；g偏差−2.96个标准差，eta偏差+0.61。仅用真值替换g均值的诊断通过率分别降到0.14983、0.31324；仅替换eta仍为0.83971、0.97198。两个任务的收费结构权重分别0.834、0.628，因此不能把失败都归因于通用分量接管。

公开几何显示来源适配8点来自四场景，目标共同8点来自一场景；相同标准化收费设计矩阵条件数分别5.61、89.13。另已完成来源同场景2点适配、2点检验的双折诊断：零余项的g预测log density 0.441，强制0.02为0.176，标准化残差RMS分别0.557、0.404。它未支持简单加回余项解决问题，也未证明几何差异就是负收益的唯一原因。

局限：旧来源每场景只有4个付费点，2/2诊断不是目标8点几何的确认。重放未执行新KG路径，解析评分不是独立部署或认证；目标开发规律已经打开。四项先验的表示接口继续保持原研究方向，但选中候选的校准及稳定独立决策收益尚未完成。

下一步先核对公开收费方程的常数偏移和价格系数联动：当前通用先验仍引入自由截距，目标单场景设计多了一个难识别方向。来源留一比较应先判断该联动是否改善条件预测，再以同一批目标观测重放；不直接改机会约束、不扩大字典、不展开服务器矩阵。若需要匹配8点的来源验证，必须明确补足同场景标签及其来源成本，不能把跨场景来源留一当成同等信息。
