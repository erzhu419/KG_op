# GP-FTA 首槽与完整终验的下一查询比较

从上一轮两个匹配任务族各取 12 个冻结首轮，按原种子恢复 8 批初始化观测。24 个历史完整先验首轮的原始查询索引全部吻合。本诊断在同一后验、两个搜索观测的预算、380 次终验上限、160 个查询、四份固定终验名单和 25 个幻想上比较首槽评分与完整守门树价值。[协议](gp_fta_cascade_query_protocol_20261120.md)

首先用 9 阶和 17 阶 Gauss–Hermite 比较，两个阶的全树赢家在两个任务族各有 6/12 不同，且 17 阶参照点值出现包络越界。后续保持原状态、名单和幻想，单槽由 Beta 阈值交换后用 24/48 阶 Gauss–Jacobi 求积，全树在包络保留集作两种随机化、4,096/32,768 两档共同 Sobol 积分。两个单槽阶和四个 Sobol 全树赢家各自在 24/24 状态一致，精化参考值无包络越界。两份高档随机化的逐候选全树值最大差为排队 $1.16\times10^{-5}$、交通 $1.33\times10^{-4}$。[紧凑读数](../paper_artifacts/v2_or_gpfta_referee_ablation_v1/cascade_query_v1/readout.json)

排队的旧独立审计基准均满足风险阈值，交通的基准风险是 9.95%–89.35%，均明确超标。首槽失败后两条后备分支的净期望收益中位数分别为 0.000950、0.01694。按族内中位数划分较低和较高后备价值，排队的首选分歧为 3/6 和 0/6，交通各 3/6。基准风险与任务族同时变化，后备价值也未形成可直接上线的阈值。

可在新一轮观测前计算每个查询的全树价值下界和上界。上界小于其它查询最大下界的候选可删除。仅剩一个且与首槽首选相同时可跳过全树求积。唯一查询不同或首槽候选已被排除时，全树目标会改变查询。剩余多项的情况可在更小集合上精算。边际区间和联合事件界在固定工作律和有限幻想下成立，Sobol 读数考察该目标下的数值排名。实际策略质量与安全由独立实验评价。

包络和单槽精化 CPU 时长中位数为排队 0.383 秒、交通 0.355 秒。带全树精化的诊断分别为 1.381 和 47.035 秒，含两随机化、两档读数而非实际运行器成本。首次恢复调用在领取数据前有 24 个配置错误，计 1.095 CPU 秒和 0 次仿真。恢复消耗 384 次初始化仿真和 10.859 CPU 秒，供来源诊断共同复用。初次积分消耗 100.971 CPU 秒，精化花费 479.268 CPU 秒。合计 592.193 CPU 秒。两次控制面锁等待、工作记录和调度 ID 一并保存。[费用与逐状态紧凑回执](../paper_artifacts/v2_or_gpfta_referee_ablation_v1/cascade_query_v1/receipts.json)
