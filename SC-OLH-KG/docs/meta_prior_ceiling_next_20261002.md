# 收益天花板的分解与下一阶段

**现有实验接近的是96候选集的收益上限，不是整个问题的上限。结构 meta-prior 的早期收益已经成立；进一步的收益应从扩大搜索覆盖和固定总预算分配中寻找。风险结构仍需按其独立贡献判断。**

## 上限来自哪里

V3共享结构紧约束层，学习方法的平均预计验证后收益为`.45844`，96候选集上限为`.45886`，搜索短缺仅`.00042`。同一组响应函数与256次验证器，在嵌套384／1536候选集中，上限为`.53319/.54353`。1536集相对原集的覆盖缺口`.08468`远大于已有搜索短缺；在原96候选内继续付费，不能取得这个缺口。

这只是评分真值诊断：新增候选没有免费送给算法其响应，也未证明算法能达到扩展上限；1536候选上限也不是连续域最优。记录：[候选覆盖诊断](../paper_artifacts/meta_prior_mechanism_v3_20261002/candidate_coverage_diagnosis.json)。

学习方法在共同8个初始点之后距原上限只差`.00925`，通用同来源先验还差`.19545`。生成族每个均值头只有3个真实函数系数及截距，8个观测足以让已识别支持的模型较快恢复响应；这解释了大部分优势在初始后验阶段出现，随后 KG 的边际收益小。通用对照也从同一来源档案学习系数分布，并非完全无来源先验；较大目标预算下追平并不否定结构学习的样本效率。

约束仍有作用：共享结构紧约束层6/8任务的无约束目标最优候选，其验证通过概率低于95%；3/8任务的数学约束最优候选不同于预计部署收益最优候选。不能把收益追平概括为“约束都不绑定”。记录：[原实验分解](../paper_artifacts/meta_prior_mechanism_v3_20261002/ceiling_decomposition.json)。

## 随后的预算转化

固定总目标调用1216次时，80批×12搜索＋256验证，与24批×12搜索＋928验证成本相同。若先验更早形成有效后验，节省的搜索调用可以用于提高部署认证能力。下一项应让所有先验共同参加预定的搜索／验证分配对照，保持同一概率约束及置信度，再判断是否转化为更高收益。该实验尚未执行，不能由早期样本效率直接推出其成功。

## 局限

V3诊断、V4归因及V5覆盖使用不同种子组，不混合成一个确认样本。检查点不是独立实验；各分层区间未作多重比较调整。预计部署收益与数学概率约束最优不同。固定／已知均值情形只用于归因，风险头仍采用 Gaussian 近似。4倍候选让现有联合 KG 的计算明显增大，本轮分片总时间约为原池的15–16倍；这只是运行时描述，不能替代受控速度比较，尚未证明总体耗时优势。来源档案成本保留，两方法使用同一档案；与没有来源档案的完整方法之间的成本比较尚未完成。当前有限字典与公共8维表示不建立连续搜索、高维泛化、正交分组或因子级HVD的完整结论。旧稿及封存2025数据保留。
