# A17：逐函数协方差方案未通过源预测验证

本轮接着完成A16后的实现与检验：256个原源任务的风险先验留出拟合，512个任务／先验组合、8192个逐批源预测。f、g所选具体函数分别提供风险协方差重分配方向，保留原模型I与独立函数族适应R；目标f/g证据不再联动风险模型赔率。宏先验校准排除正在评价的整个配对种子，且源函数拟合排除该函数的全部标签。

**停止此协方差重分配版本，不进行目标验证或推荐回放。** 各头独立来源相对同池I/R也退步，区间[−0.00413, −0.00220]。宏先验平均I/F/G/R质量为0.7851/0.0601/0.1360/0.0188；来源对不同头的关系存在明显异质性，而该版本仍共用一份跨档案宏先验。A16的关联是有效线索，但不能直接当作此协方差形式有预测收益的证据。下一步[A18](../performance/meta_prior_function_covariance_attribution_plan.json)仅分解保存的分支质量与权重，区分共同权重、重分配形状及q变化的影响，不调参复活此版本。

通用先验控制精确还原同池I/R，两类来源相对其原模型分别提高0.00336、0.00366；这些增量不能和学习先验增量直接比较为绝对预测优劣。跨档案校准每个外层留出使用30个历史源档案，即184,320次历史源调用；待应用档案另有6144次。该信息量大于旧逐档案校准，对照也使用同一信息池，不声称同源成本优势。没有新增调用。

5项新测试通过，256/256原ARD拟合收敛，原I预测最大误差6.22e−15。8阶宏积分精度不足（差0.00283）；保留预定16阶主参数，复用已存数组以24/32阶确认，最大差1.36e−8，rho的16/32/48阶检查也通过。初次粗阶诊断已保留，未重跑源拟合。总计92.01 CPU秒，两个进程VmHWM最高140.2 MB；无服务器任务、拉取、新样本、目标评估或KG。[完整结果](../paper_artifacts/meta_prior_function_covariance_source_a17_20261003/validation.json)与[初次数值诊断](../paper_artifacts/meta_prior_function_covariance_source_a17_20261003/initial_quadrature_diagnostic.json)均保留。

局限：整种子排除避免用其分数校准自身宏先验，但设计仍来自已检查过的开发源档案；这些区间未校正多重比较。源档案内部固定支持，没有高频风险变化样本。本阶段否定该协方差变体的晋级，不否定原结构meta-prior闭环或此前限定的样本效率结果。
