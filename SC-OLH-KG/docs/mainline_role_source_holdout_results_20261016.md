# 当前角色算子的来源留出检验（2026-10-16）

结论：首次传播改善目标预测；第二次传播没有稳定的风险／相对排序收益，不支持统一风险或协方差补丁。冻结部署模型，保留初始化传播＋后续逐点为工作基线。已按[协议](../performance/manifests/mainline_role_source_holdout_v1.json)完成四折；本轮实际执行的是当前role投影与成对raw更新，而非阶段36的同任务f条件化。

Inventory／Queue各64个来源策略，每折48训练＋16留出，整策略的全部raw一起留出。各取两个留出锚点的第一条成对f/g观测，其余14点始终未采样。四折、两家族的预测全部冻结后才打开评分标签；目标差参考使用首锚点剩余两条raw。下表为最终两轮的未采样MSE，目标差为相对首锚点的预测误差。

两家族等权，首次传播相对从来源起逐点使f／目标差MSE下降17.10%／17.78%，g却增加5.66%；g平均偏差由＋0.050565变为−0.010117，整体偏移减小并不代表逐策略预测更准。第二次传播相对首次后逐点使f／g／目标差MSE增加3.53%／0.66%／3.34%。扣除独立评分raw的均值噪声后，比较方向相同。

后续传播的家族差异明显：Inventory的f／g／目标差分别恶化13.18%／9.83%／12.32%，Queue改善14.36%／4.09%／12.71%。但g在每家族都只有1/4折改善，合计6/8组恶化；Queue平均收益由fold1抵消其余三折。第二次传播仅改变两个相对差符号，一正一负，方向准确率仍88.39%；8个评分池的目标预测argmin全部不变。完整传播相对从来源起逐点的两次argmin变化都在首次传播时发生。

风险预测的矩评分并非恶化：Dawid–Sebastiani均分由−2.47879降至−2.83406，标准化平方误差0.564→0.540；这是含预测方差的矩评分，不是精确混合对数密度或部署收益。不能只用均值MSE否定全部不确定性更新，也不能用矩评分改善替代决策证据。

噪声大值主要在更新前已存在。最终预测episode方差／观测样本方差的汇总比为f54.57、g9.20；第四折（fold3）分别约244倍和35–38倍，贡献总预测f／g方差98.60%／86.87%。该折source0已达f243–244倍、g35–38倍，两轮改变很小；其余折f约0.56–1.89倍、g0.81–4.21倍。

补充的[纯保存矩诊断](../paper_artifacts/mainline_role_source_holdout_v1/noise_moments.json)进一步定位到fold3的同一个物理策略0：两个家族合计占全部预测f／g噪声98.13%／84.48%。全112点exp(Eeta)／观测方差只有0.927／1.017；加上保存的eta方差，用匹配单高斯参照exp(Eeta＋Var_eta/2)便达到56.97／6.95，实际混合期望为54.57／9.20。可见边际eta方差的指数放大足以解释主体，g的高阶矩差异再放大约1.324倍；这不是具体节点归因，也不支持以exp(Eeta)替换正确的混合期望。

策略0是[真实来源档案](../paper_artifacts/legacy_joint_bridge_v1/inputs/FactorShockStatePolicyRZDT1/archive.json)中的50维全15低频策略，两家族相同。fold3训练48点的策略均值范围25–85，49/50个坐标的训练最小值高于15；它在公共均值方向确实外推。该点source0的eta_f／eta_g方差已为13.20／15.59。因此下一步对象是这一实际边界的噪声不确定性外推，不是全模型统一均值偏高。

限制：统计单位仅两个来源家族，四折训练集重叠，112策略—家族对不是独立任务。只有三重复的评分标签，未构造真实chance可行标签。本轮为d50同源家族的部署算子留策略检验，独立新任务投影及一个锚点后的截断都不等同d1000初始化10点；不直接与阶段36数值比较。原精度不变，来源拟合的4个低ESS标记保留，未据此筛折。
