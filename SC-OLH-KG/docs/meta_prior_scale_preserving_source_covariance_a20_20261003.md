# A20：保留风险尺度后，来源共享的明显退步得到修复

保留A17的四分支、来源校准参考分布和整种子留出方式，只将F/G的等权重协方差改成保留原风险尺度的构造：设风险函数协方差为C、总预算为T、选中函数的原协方差为D_S，则B_S=T(C+D_S)/(T+tr(D_S))，再对(1−ρ)C+ρB_S积分。风险头决定方差大小，f/g选基提供共享方向；集合内及其余函数的方差比例保留，非截距均值仍为零。

全部256个源函数留出折、512个先验配置、8192次逐步预测完成。每次外层校准排除当前整个种子，内层先验及选基只使用其余七个源任务。下表为学习先验的逐步对数预测密度差，16个种子分别配对：

|---|---:|---:|---:|

独立头相对A17改善+0.003546 [0.002662, 0.004386]，15／16种子改善；相对原模型的可靠优势尚未建立。纯F在独立头仍有13／16种子退步，平均−0.000616，区间跨零；纯G平均+0.000863，区间也跨零。因此保留F/G独立推断及原模型分支，不能据本结果强制共享或挑选G替代完整模型。

**A18/A19指出的尺度问题确实可以修复，但修复尺度不等于完成结构学习。** 本结果支持将冻结的完整混合模型送入目标预测检验。通用先验F/G与I完全重合，结果与A17及同池I/R一致；其正收益来自既有R校准，没有新增函数方向信息。

7项测试通过，包含直接高斯条件计算、重复候选、观测时间顺序及原内核回归。原模型复现误差6.22e−15；宏积分16/24/32阶最大差4.87e−8，ρ的16/32/48阶最大差2.00e−15，均通过。复用256份η协方差和f/g选基，仅重拟合原完整η先验；75.10本地CPU秒，VmHWM163.6 MB，无新样本、拉取、派发或KG。

## 局限

这是开发阶段的源任务留出证据；独立头的优势不确定，也未检验目标高频／支持变化或任何决策收益。校准信息池包含30份历史源档案，184320次既有来源调用，加上应用档案6144次；不能与旧单档案校准声称同源成本。保持η点估计尺度也可能保留其漏学方向，尚未实现联合潜在支持或高维表示学习。区间为未作多重比较校正的名义配对区间。
