# 运营闭环结果与下一步

本阶段完成，尚未建立独立决策收益。预先固定的8个新目标上，因子族风险先验5/8改善，平均log风险RMSE为0.344，对照0.354；局部分量改善，共同及数量分量退步。新增768次共享重复。

另8个新任务的完整结构、风险消融、同来源通用先验共24单元全部完成，均未通过独立认证。每单元共同初始8点、共24点×12重复及928次独立验证，目标预算1216，来源1536次全部复用。配对总分配29184次、实际模拟18776次。单次CPU上限在单元边界检查；首段21单元、续段仅补3单元，共53.77秒单核CPU，未派服务器任务。

7/8任务在96候选库内没有可行策略，五个固定公开基础库存锚点也未改变这一情况；不据此推断连续空间全局不可行。唯一可行任务95014有19个可行候选，三组均从推荐76转为64，真实预计验证收益从0.64615降至0.00003445。独立验证正确拒绝。

候选64的12次观测均值偏低1.54个真实标准误，样本方差为真值的58.2%；模型几乎沿用该均值。仅纠正均值中心、保留其余不确定性，预测验证概率从0.870降至0.264；仅揭示真实风险则仍为0.867。初始16/16、终点24/24粒子与Gaussian推荐相同。当前主问题是均值乐观选择：原tanh字典未精确包含线性收费项、策略余项均落在0.02下限、均值噪声仍用单批样本方差，尚未分离三者各自因果份额。

完整记录在`paper_artifacts/inventory_physical_risk_20261004/`的`new_targets.json`、`decision_interface.json`、`closed_loop.json`及`feasible_task_attribution.json`。归因入口`performance/analyze_inventory_meta_prior_closed_loop.py`只重放付费记录，终点概率复现误差5.55e−16，约0.10秒CPU；粒子概率的两项数值测试通过。冻结协议参数和旧M1均保持。

下一步按顺序执行：

1. 在公共函数类中纳入原始收费量，来源学习支持与系数分布；先做来源任务留一，与已知线性账单控制比较。物理记账本身不算学习贡献，这8个目标不用于选支持、尺度或余项下限。
2. 接入同批均值/方差联合似然，按风险粒子更新均值系数及权重，保留相关性。先复用付费记录检查，再决定KG接口；独立三头Gaussian幻想不能直接代表联合后验。
3. 用来源付费记录统一固定成本预算档位，保留预算1，预先固定策略类。随后冻结新目标和终点，做小规模本地完整配对；不按目标oracle移动边界，不扩当前预算或启动大矩阵。
