# 来源公共近邻的目标差值与竞争覆盖

模型、来源拟合、搜索、终端、预算及数值精度继续冻结。本轮只读Stage58已封存的24个来源档案／折／家族组、四个后端和prefix10／13共192份预测，以及其原有未用评分重复。Stage65／67的24个d1000几何、全部9臂、三流正反例和费用原样保留，不读取目标真值用于配对或选择修正。

阶段一独立通过scheduler保存全部来源近邻名单。只用原16个held策略及既有公共表示`legacy_public_coordinates(X_integer/100)`：原65维公开映射按既定规则归一化后的前10列，d50来源与d1000搜索沿用同一函数。距离为这10列的均方差；每点取一个非自身最近邻，距离平局按held原顺序，取无向并集。沿Stage61的k=1及去重规则，不重拟合缩放、不扫描邻居数。近邻距离直接用公共10维，模型内部已有来源标准化保持不变。档案JSON容器虽包含响应，配对过程不访问响应字段或预测；观测状态仅附注，不影响配对。

全部24组配对写入`fixed_pairs.json`并完成阶段一后，阶段二才计算评分。固定对全部保留，按当前前缀分已观测—已观测、已观测—未观测和未观测—未观测。原final13策略使用未参与历史的后两次重复，never-observed3使用全部三次，prefix10不额外使用即将进入历史的首重复作为标签。记录目标均值差、两端重复数、方差、独立样本差的标准误和删去单条重复后的差值符号稳定性；这些都是描述，不据此重选策略对或增加决策阈值。

来源生成器在策略之间连续调用新的模拟随机量，没有跨策略共用随机块，不按重复行号拼造CRN。独立样本均值差标准误为`sqrt(s_i²/n_i+s_j²/n_j)`，不等于后验目标差标准差。经验可行性沿旧评分的`g均值−tau+z(1−alpha)×样本SD≤0`，少量重复不构成安全证书。

分别保留全固定对、单臂原终端预测资格`probability_violation≤0.5`、两臂对称共同资格，以及经验可行分层。先组内汇总，再按家族描述；档案／折／近邻对重叠，不当独立任务。四后端和全部失败、低ESS提示保留。目标搜索使用一次联合后验抽样后的风险margin；来源没有保存相应抽样或联合协方差，其搜索资格及采样竞争记为不可识别，不能拿来源终端资格代替。

先确定旧来源数据能检验的目标排序范围，再判断是否支持一项最小修正；本轮不拟合或应用新修正，不使用目标结果选温度、风险补丁或门槛。证据不足时保留缺口，不用统一均值误差改善代替未采样候选的决策价值。

两个小阶段分别通过scheduler完整node001–node006池执行，每阶段1CPU、vram0、BLAS单线程，严格先配对后评分。仿真／终验／真值／拟合／模型与后验恢复／raw条件化／RNG均0；所有尝试、CPU和历史费用单列，完成阶段不重跑。仅拉紧凑汇总，原始重复、全配对明细及模型留服务器。必要替身检查检验无标签配对、独立重复与对称资格、缺失预测和正反例保留。
