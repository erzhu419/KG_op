# 历史先验接入后验与balanced4

复用历史实现，已完成两种布局的32个响应头系数先验、16个Gaussian稀疏后验参考及8个完整四响应模型身份。来源仍为task2–5的48个既有批次，地图直接恢复，task0仅进入已有两次普通观测。旧系数证据计算从`meta_prior.py`抽出共用，原训练仍调用同一算法；完整身份的f/g证据共同更新一个权重，实际后验调用现有原始观测密度与Gaussian矩投影。[代码](../performance/connect_historical_prior_posterior.py)、[结果](../paper_artifacts/historical_prior_posterior_connection_v1/results.json)、[保存的先验／后验及动作](../paper_artifacts/historical_prior_posterior_connection_v1/states.json)。

单位与坐标已正确衔接：来源响应和观测方差标准化后调用既有有限系数先验，再将均值、完整协方差与独立差异方差转换回物理单位。真实来源数据的仿射单位检查误差小于1e−15。旧风险缓存的task0轴与当前风险法则最大差3.4387，使用当前法则保存的开发坐标，未重训地图。原始观测积分最大相对误差2.51e−10，共同身份权重与旧Bayes混合函数一致。

两布局的balanced4均保留两个合格重复点并加入四个新点，包含原单新点集合；选点优先级与lookahead都使用同一部署效用、付费目标incumbent和362调用总额。复用旧动作生成与shortlist构造，没有重写KG或验证器。单新点政策的旧登记元数据曾多包含一个非活跃点，已修复计数位置；活跃集合和已算数值未改变。系数超先验的两个既有回归与动作集四个针对性测试均通过。

布局5的六个动作完成原始似然lookahead。粗规则表面最好点的净值0.103917包含0.073554基准漂移，随后只细化同一保存状态／动作：[完整精度记录](../paper_artifacts/historical_prior_posterior_connection_v1/precision.json)。

后续三条规则通过登记的漂移／身份权重／证据误差门槛，主要误差来自最初四幻想的粗积分。128／16已足以通过本例门槛，可作为后续低成本起点。单动作仍是原单新点集合中的点，不能据此宣称balanced4改善决策。

接口重放4.89单核CPU秒。精度诊断实际31.18秒，超过登记15秒上限；超限结果原样保留。原来仅在每条规则前检查预算，长规则无法及时中断，已增加计算中的CPU截止并验证会触发。此次没有新仿真、验证器、来源链、服务器工作或独立任务。

## 限制及下一步

本轮接入的是Gaussian来源标签有限系数参考，尚未替换当前96系数完整原始来源法则。旧系数二阶矩没有去除拟合噪声，Gaussian稀疏参考与原始似然后验分别登记；16次稀疏拟合中布局6的spectral/head-specific/g达到40轮仍未收敛，保留HOLD，没有提高迭代上限。地图上游及task0是开发数据，八候选子集和单动作精度通过不能充当全政策排名、因子恢复或独立部署优势。

历史V47拟合噪声去卷积及共享／任务分块现已接续，新地图法则也已接入原始来源似然：[后续适配记录](historical_source_covariance_adaptation_20261007.md)。来源样本变换虽改善重叠，16组仍未达到原登记精度；下一步复用collapsed来源采样器完成新法则的后验条件化。通过后再用同一保存开发状态、受CPU截止约束且足够精确的规则比较单新点／balanced4，保留强基线与全部负结果。
