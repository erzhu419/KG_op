# Stages196–198：小样本方差影响来源后验，联合对照精度尚未闭合

已知来源风险坐标、原32条风险统计和均值条件预测复现通过；风险条件任务残差与公共协方差保留，新增策略与原风险训练策略不重叠。方差积分使结构训练条件预测方差平均增加14.80%/13.63%，GP增加17.11%/18.06%；两例结构观测密度仍低于GP，平均方差调整方向未反转。[条件诊断](../paper_artifacts/legacy_joint_population_f_known_source_latent_noise_v1/results.json)。

实现48个新增来源batch的联合原始观测更新：完整均值／风险头相关协方差，共享风险法则，Gaussian均值和chi-square样本方差似然各计一次。Gaussian条件采样恒等式和风险似然差核对通过。四链固定512预热＋1024保留，结构两例及layout6 GP通过登记的Rhat、ESS和分段方差精度门。layout5 GP的分段方差最大差异15.47%超过15%，保留失败，不追加采样。全套对照尚未通过。[联合试点](../paper_artifacts/legacy_joint_population_f_correlated_source_raw_update_v1/results.json)。

三例通过的联合后验相对固定噪声后验，方差比均值约3.18–3.39、中位数1.21–1.57；极大比值约27–33倍。平均值受少数小样本方差点影响，不能解释为所有点方差都增加三倍，也不能据此主张泛化改善。

随后完成确定性单batch后验积分，并逐点复现Stage196的联合观测密度。结构后验方差比中位数1.98/1.26，最大43.58/51.92；GP方向相似。极值均来自source5、policy59，其样本噪声仅占结构潜在函数先验方差约0.51%/0.55%。方差比与样本噪声占比的排序相关为−0.93/−0.88。当前风险法则下，固定小样本方差会使这些点的后验不确定性明显偏小。[确定性结果](../paper_artifacts/legacy_joint_population_f_single_batch_raw_posterior_v1/results.json)。

解析积分和原48条来源更新已完成，见[Stages199–204](orthogonal_meta_prior_stage199_204_20261007.md)。旧GP失败保留，新计算方法通过；原始似然从未条件化群体先验出发，每个样本方差只计一次，协方差重新学习仍需继续。

限制：原来源风险训练仍采用log-variance Gaussian近似；本轮修复原近似法则下新增batch的条件似然，没有重新学习原来源协方差。单点确定性积分不等于48点联合后验，也不补过失败的GP精度门。没有新的留出决策证据；覆盖候选仍停止，原生截距混合仍为参考，完整模型HOLD，四项原始meta-prior原则保留。
