# 成熟先验接口与Inventory累计成本风险

本轮完成两个源码接口，未改旧M1、旧应用结果或论文：

- `core/verification_kg.py`接收三头均值、完整潜在函数协方差和批次标签噪声，保留原27节点KG与同一验证效用。已有系数模型和`predict(full_cov=True)`核模型均可接入。
- 官方HyperBO入口公开来源学得的统一标签噪声，明确不消费逐点噪声；其潜在协方差不含新观测噪声，KG只加一次。源码接口检查不等于官方训练完成。
- `problems/inventory_cost_plan.py`实现根据当前库存订货、需求消耗、缺货和期末库存的物料平衡。公开确定需求计划决定可计算轨迹；未知价格及风险参数产生独立逐期成本、跨期共同价格和Gaussian数量成本扰动。累计风险确为`floor+A²Lambda+N'BN+N'omega`。

所有方法获得同一8维公开状态/暴露坐标。来源学习仍使用响应标签，目标非截距系数均值仍为零。Gaussian独立重复支持原验证器；log样本方差使用付费样本和偏差校正，不返回真实风险标签。

冻结接口检查完成8来源×16策略×12重复=1536次来源调用，目标8策略×12=96次调用。共享这些记录进行M1、同来源全字典和明确标记的核接口对照；没有后续搜索或验证调用。风险ARD收敛，三条接口均返回有限后验与KG。15项数值检查通过，包括物料平衡、模拟风险分解、噪声只加一次及原KG跨动作块与密集计算等价。接口检查约0.64本地CPU秒；新结果位于`paper_artifacts/inventory_meta_prior_interface_20261004/check.json`。

来源风险设计有9列且满秩，但列归一化条件数约153246；整个候选库约11230。这里不能据满秩宣布共同/局部风险因子可可靠恢复。源码字典CV只选择单个响应代理，其中约束头选中正弦函数，也不能解释为恢复了物理结构。
