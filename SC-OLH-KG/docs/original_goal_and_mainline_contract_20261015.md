# 原始目标与主线合同（2026-10-15）

本文件固定本项目的研究问题，并约束后续实现、评估与下一步建议。本次用户已授权先记录边界，再执行真实 73 点候选库、两轮、四臂实验；具体参数和实际结果由新阶段 manifest 与结果文件登记。旧 draft 中的 `scientific_execution_authorized=false` 不代表本次授权后的执行状态，旧文件保留其历史含义。

## 1. 原始问题

利用离线来源任务学习 meta-prior，把超高维策略之间可利用的结构关系带入新任务；少量付费仿真后，通过后验更新把信息传播到未采样策略，改善预算内的搜索与最终推荐。

主链是：来源数据 → 函数空间超先验 → 新任务后验 → 未采样策略预测与排序 → 查询或停止 → 独立终验。形式上可写为 `F_t(x)=Σ_j β_tj φ_j(ψ(x))+r_t(x)`，来源任务学习表示、基函数或系数超先验中实际启用的部分，新任务观测更新任务后验。固定表示或候选库可以是受限实例，但必须说明学习发生在哪里。

“超高维”指实际策略空间的维度与仿真代价；合理的结构假设、公开描述符与限定任务族是问题的一部分。研究不要求无假设地恢复任意高维黑箱。当前 73 点桥接实验检验有限候选库上的信息传播与决策价值；动态高维候选生成仍是后续主线，不能由此直接宣称完成。

原始依据：[GPT_plan](../../markdown/GPT_plan.md)、[GPT_meta_assumption](../../markdown/GPT_meta_assumption.md)、[结构先验与 HVD 计划](structural_prior_hvd_backend_plan.md)、[2026-10-02 主线恢复](meta_prior_reorientation_20261002.md)。

## 2. 四类 prior 的角色

- **正交性**：在声明的来源分布或参考测度下减少基函数冗余，帮助系数学习；它本身不等于降维，也不保证目标任务正交。
- **稀疏性**：以活动概率或收缩先验集中学习少数有效方向、频率或函数块；支持可以随任务和输出头变化。
- **可加性／低阶交互**：限制组合复杂度，同时保留实现中允许的交互；不能把所有任务强制解释为完全可加。
- **低频性**：优先学习来源数据支持的平滑、低频响应；频谱选择、提议分布和函数系数先验的作用应分别记录。

这些结构服务于样本效率，不要求每项在每个任务、每种组合下都产生非负增益。宣称四类结构共同有效，需要实际启用状态与相应对照；代码存在或名称包含 structural 不能替代实验事实。

## 3. 三种 coupling 不混称

1. **策略与暴露表示的关系**：策略如何映射到轨迹、占用／暴露或公开描述符 `ψ(x)`。固定余弦描述符只是表示选择，不能独自证明学到了响应耦合。
2. **跨策略函数后验耦合**：共享基函数与来源学习的系数超先验形成跨点预测关系；观测一个策略后，未采样策略的均值、不确定性或排序发生有依据的变化。这是当前主实验要直接测量的传播。
3. **物理风险／共同冲击耦合**：轨迹内风险分量、共同随机因子与累计风险分布之间的关系，可由 HVD 等模型表达。其解释与识别问题独立登记，不能把恢复真实物理因子设为证明第 2 类决策价值的前提。
