# Meta-prior 最小闭环：本阶段结果与下一步

已接通 `source_function_prior.py → 三个目标 GPR → 在线 KG → 独立验证`。source 标签分别选择 objective、约束均值和 log-variance 的函数支持，学习系数协方差；非截距系数先验均值保持为零。所有算法使用相同完整初始设计和候选集，不使用 source 好策略初始化。

冻结协议为 `performance/meta_prior_mechanism_protocol.json`。8 个 source 种子 × 4 个情形 × 4 个算法，共128运行全部完成；其中种子0本地完成，其余7个通过scheduler完成。每任务先评估8点，再进行16次在线评估，候选96点；每点12次重复，推荐后独立验证256次。source档案每种子6,144次模拟调用，每算法目标搜索和验证共544次；source跨4个目标情形的摊销费用另列。结果见 `paper_artifacts/meta_prior_mechanism_v1_20261002/summary.json`。

共享结构主情形的8个目标任务结果如下。RMSE依次为 objective／约束均值／log-variance，决策指标为预先规定的 penalized regret。

| 先验 | 初始8点后 RMSE | 最终 RMSE | 平均决策指标 | 独立验证通过 |
|---|---|---|---:|---:|
| target-only | .528 / .526 / .381 | .340 / .369 / .323 | .222 | 8/8 |
| 同source、固定字典 | .523 / .521 / .336 | .357 / .372 / .288 | .220 | 8/8 |
| source学得函数先验 | .254 / .312 / .249 | .211 / .290 / .222 | .182 | 8/8 |
| 仅知结构的诊断对照 | .049 / .059 / .233 | .021 / .045 / .148 | .112 | 8/8 |

学得先验相对固定字典的三个初始／最终预测RMSE差值，其按种子配对的bootstrap区间均低于零。32/32任务的后验误差和首次在线选点改变，17/32最终推荐改变；source非截距先验均值在所有记录中为零。主情形的决策改善只发生于2/8任务，其余6个推荐相同；平均差为−.038，描述性95%配对bootstrap区间为[−.095, 0]。当前证据支持函数先验改善预测，尚未建立稳定决策收益。

选基瓶颈有明确实例和跨种子重复：24个学得头全部选入同一坐标的线性项及正弦项，23个缺少真实二次项及其同坐标余弦替代，15个缺少真实交互项。种子0重复两项相关系数为.942。旧选基使用绝对相关／低频得分，且4维选择时不执行其大于6维才启用的独立性折扣；白化发生在选择之后，不能补回被漏掉的函数。结构诊断对照显著更准，说明现有离线识别未充分利用source信息。

反例按协议保留：支持错配时，学得先验最终objective／约束90%区间覆盖分别为53.5%／63.5%，约束RMSE .563，高于固定字典的.361；高频风险情形的风险覆盖为54.8%；风险支持分离时风险RMSE .303，高于固定字典的.260。这些模型区间不能作可靠安全证书。最终独立验证仍为每情形7或8/8，且推荐真实可行率全部8/8，决策任务存在可行性上限效应。

下一阶段先用source任务交叉验证评价加入函数后的条件预测改善，避免高相关函数重复占用容量，并保留二次项／低阶交互。随后让未选函数保留弱先验，由目标证据更新支持，而非冻结硬截断；复用已有稀疏后验接口。新的目标诊断要预先设置更有约束作用的难度层次，使用独立种子，完整保留本轮结果及反例。暂不扩大应用或SOTA矩阵。

## 限制及数据记录

这是公开8维输入、68函数字典的机制诊断；尚未学习高维状态／轨迹坐标。四项结构性质在整条路径中共同起作用，本轮没有识别各自独立贡献。风险头采用偏差修正的重复样本log-variance及高斯似然近似，约束均值使用样本方差代入观测噪声。KG是三个独立头下局部线性化损失的KG，使用现有精确线包络，不能称为精确联合概率约束KG。8个主任务及bootstrap区间均为开发诊断，不能替代独立确认或投稿证据。
