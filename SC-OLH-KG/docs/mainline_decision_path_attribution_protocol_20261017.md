# 48个任务流的查询至部署归因

固定Stage76全部24几何×2观测流、9个终端对照和旧／新两套终验，共432对／864结果。AFTER、来源模型、搜索、终端、门槛和随机流均冻结；只读已保存候选、观测、最终排序与名单过程、终验及缓存真值。不拟合、恢复后验、补预测、补真值或新增仿真，全部实质分析由scheduler在node001–node006执行。

实际结果继续使用旧端AFTER−POINT的C和带符号G，保留7012空基线、全部正反例、失败及费用。48个任务流分别展示，同几何两流先平均，以24个几何为统计单位；缺流不填补。7017和7013是预先指定的正负焦点，不改变分析样本。

按物理策略连接本历史的完整实际候选池、最终观测池、终端名单、实际安全验证集合、实际获证且真实可行集合、最终真实可行部署。逐层以缓存真值中最优可行质量Q计算差额，分成未采到、名单遗漏、未执行验证、安全未通过、比较／选择未部署五项；只有完整嵌套链才汇总搜索差额与终端四项差额。全候选池仅三角色历史及其同历史native交叉可用，其余对照不借用别人的池。任一集合有真值缺失、为空或未保存，其Q保持未知；未获证任务单列C和实际失败路径，不能把Q填0。

这些差额是事后可见质量机会，不是保证可获证的收益或因果贡献。全部已观测好点同时对比初始化与实际部署，避免把劣于已部署策略的遗漏算成损失。逐点保留真实查询返回、已保存目标／风险分量、名单插入前后槽位、安全与实际比较；没有执行的比较不补算。两流策略ID不当作相同物理身份。
