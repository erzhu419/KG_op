## 核心结果与论点变化

新增两种控制均来自原64-profile库：Standardized DCT maximin使用与源方法相同的18列标准化结构坐标，不读源结果；Source-greedy portfolio使用相同的源档案、噪声统计与安全/目标秩，以跨源任务的最佳已选分数为贪心目标。二者均保留原目标噪声、插值、短名单和独立验证流程。

| 合成实验，480个任务-网格cell | 可行覆盖 | 真可行认证 | 错误认证 | 平均惩罚损失 |
|---|---:|---:|---:|---:|
| Source-scored atlas | 91.7% | 47.3% | 0 | 0.163 |
| Standardized DCT maximin | 81.0% | 31.5% | 0 | 0.274 |
| Source-greedy portfolio | 87.1% | 37.1% | 3 | 0.178 |
| 原Unstandardized DCT maximin | 37.5% | 10.6% | 3 | 0.746 |

源方法相对标准化控制的逐维认证增益为16.25、15.625、15.625个百分点；相对贪心组合为11.25、11.25、8.125个百分点。每个分辨率内按八个固定机制分层重采样20个配对任务，10,000次bootstrap；两组比较的逐维区间均高于零。480个cell对应160个潜在任务在三个网格上的重复，不能当作480个独立任务。

收益有明确范围。d=1000时，相对标准化控制净增25个认证，置换和有效秩增长贡献24个。d=10000稀疏高频任务中，贪心组合覆盖20/20并认证6/20；源方法与标准化控制均覆盖0、认证0。正文和热图保留这些结果。

Energy V3的源方法为60/90，原无标准化对照70/90；新增标准化对照54/90、贪心组合62/90，各臂无错误认证。源方法相对标准化控制的等区域平均差为0.043，描述性区域bootstrap区间[0,0.096]；相对贪心组合为-0.013，区间[-0.04,0]。因此当前外部证据不支持源方法优于最好的无源设计。

采用匹配标准化控制后，总调用的摊销交点是总体15个目标、逐维15/16/16个目标。M=20时，每个真可行认证的平均调用数为源方法411.3、标准化控制639.5、贪心组合612.7。这一结果与“总调用相等”的交点不同，也不包含对弃权、目标质量等因素的经济估值。
