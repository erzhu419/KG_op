# 来源结构先验的共同八点归因回放

本阶段复用已保存的 95001–95008 八个目标任务的共同八点记录，没有生成新目标观测。每个任务分别用三种均值先验重建目标后验：来源选择的四个公开 billing 函数、同一来源档案的全字典先验、完全不读取来源标签的 target-only 全字典先验。风险后验分别固定为来源学习的 factor-family 分布和同来源 pooled scale；两种风险上下文用于检查均值归因是否被风险选项掩盖。

在 96 个候选上，source billing 的平均 f RMSE 为 0.0529，full dictionary 为 0.5517，target-only 为 0.4261；g RMSE 分别为 0.1077、0.2647、0.1961。这个差异来自来源结构选择和来源系数尺度，目标八点只做统一的后验更新。

决策收益受到任务可行性天花板限制：八个任务中只有 95007 和 95008 的最佳真实验证收益超过 1e-8。两任务平均真实预计收益为 source billing 0.8475、同来源全字典 0.8419、target-only 0.8363；六个其余任务的所有候选均接近零收益。风险上下文没有改变三种均值先验的推荐或真实收益，因而本回放没有建立风险先验的独立决策增益。

这一步支持一个限定结论：在相同初始观测下，来源学习的公开 billing 结构确实贡献了早期均值预测和小幅候选排序改善；它不是单纯把历史好策略直接放入初始点。它不能证明跨任务稳定的部署优势，也不能替代独立确认，因为记录来自同一来源档案和同一合成生成器。

结果、逐任务推荐和误差保存在 `paper_artifacts/inventory_physical_risk_20261004/source_prior_attribution_replay.json`，实现为 `performance/compare_inventory_source_priors.py`。下一步只冻结这一均值归因和当前联合更新，补一个独立来源/目标小批次；成熟方法比较仍需先完成信息合同接口，不再扩展风险变体。
