# 固定来源近邻的均值差与传播增量分解

冻结模型、搜索、终端、精度与预算。仅复用Stage70封存的24组、282个公共近邻对及四后端两前缀的保存预测与评分证据；不重新配对，不读取目标真值或重新读取来源raw评分。全部正反例、平例、缺失预测、原资格、低ESS和历史费用保留。

同一固定对在前缀t的POINT、AFTER、FULL均值差记为P_t、A_t、F_t。逐对记录P_10、初始化传播增量A_10−P_10、后续自身更新P_13−P_10、AP后续残差(A_13−P_13)−(A_10−P_10)，以及持续传播F_13−A_13。这五项之和为F_13；保存native差值作为原参照。POINT仅在两端当前都未观测时代表来源零观测prior差，其他情况称逐点更新参照。AP后续残差包含不同初始化状态下自身更新的交互，不称为新增跨策略传播。

全部282对分别保留原OO／OU／UU分组。初始30个UU对逐对追踪到13，标记两端是否后来观测；最终6个UU对单列，不用它们替换原30对。对始终未采样的端点，P和A的前后差值直接给出是否保持原冻结状态；不恢复后验，不归因到单个anchor或协方差分量。

使用Stage70同一份未用重复均值差作为经验比较依据，记录正确→错误、错误→正确、同对、同错、标签平局和未知。将传播改变量与原误差方向对照，区分朝标签移动后越过标签、远离标签及无变化，并保留绝对差值误差的变化；均值误差下降可能与排序恶化同时发生。删除单条重复的符号稳定性、独立重复误差与经验可行性只附注，不筛掉策略对。资格沿原来源终端定义，目标式联合抽样资格保持未知。

本轮不扫描缩放系数、偏移、阈值或采样温度。先判定新增未采样错序是否有跨来源一致的均值差机制，并检查同一机制下的正例和原prior错序；纯粹“传播改变了顺序”不构成修正依据。若不存在能同时解释正反例的一致机制，停止这条均值补丁方向，保留初始化传播及现有模型；不再为该方向追加同类分层。

全部实质分析通过scheduler在node001–node006池运行，单CPU、vram0、BLAS单线程，仅一项保存数组分析并直接汇总。仿真／终验／真值／拟合／模型或后验恢复／raw条件化／RNG全0。记录全部尝试、验证和分析CPU，仅拉紧凑汇总与原30个UU对的表；完整282对明细留服务器。小替身只检查恒等分解、同对跨前缀身份、过冲与误差下降并存、标签平局和缺失对照。
