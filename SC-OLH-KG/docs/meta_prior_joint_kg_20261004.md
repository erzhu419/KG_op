# 联合KG与预算分配：结果及下一步

联合KG已接入均值/风险完整协方差，采样与推荐共用相关Gaussian矩下的有限验证效用；实际付费更新仍用联合粒子似然。六项检查通过，覆盖独立模拟、直接高斯条件计算、零信息价值和预算停止/继续判断。

首批新任务95017–95018，三个来源预算、四组方法，共24单元。每组均5/6通过验证，零错误认证。严格预算下学习风险KG相对同总预算初始即验证的平均预计收益仅高0.000031；两个来源预算档分别低约0.0140、0.0166。全部终点的Gaussian与粒子推荐相同。固定24点搜索在粗积分全零后仍重复选0；一例第12点的高阶KG约4e−6，而扣掉验证预算损失后的净值为负。

据此加入净信息价值停止规则，使用125点积分，在独立新任务95019–95020上再跑24单元。12个搜索单元均在9–11点停止，验证获得1084–1108次重复；相对24点上限，2028次调用转入验证。每单元总预算保持1216。各方法均3/6认证成功，实际收益与初始即验证相同，零错误认证；一个任务三个预算档均无库内可行策略，另一个的初始推荐已是库内最优。

两批闭环分别耗30.39、16.53秒单核CPU。结果及冻结协议分别为`joint_kg.json`/`inventory_joint_kg_protocol.json`和`budgeted_joint_kg.json`/`inventory_budgeted_joint_kg_protocol.json`；归因见`joint_kg_attribution.json`，均在既有实验目录或`performance/`。没有服务器任务或数据拉取。

下一步固定联合更新与预算规则，转入来源先验贡献比较：先用已有共同8点记录核对同来源通用均值先验、无来源对照及成熟方法接口，再冻结独立来源/目标比较。检验重点是结构先验的早期决策价值、校准和来源成本；KG是否继续采样由净信息价值决定。

当前限制：两批各仅两个任务规律、同一来源档案，预算档高度配对且算法不同；收益不能跨批混合归因。早期推荐多已接近上限，风险先验相对汇总尺度的独立增益仍未建立。四项结构先验的完整贡献与成熟对照仍是投稿缺口。
