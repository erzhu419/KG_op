# U1完整路径联合均值—风险更新

`representation/joint_function_risk.py`已将同批均值与样本方差的联合似然贯穿付费轨迹：约束均值噪声用潜在环境方差/n，log样本方差用精确χ²密度，保留跨策略及g/eta协方差。各Gaussian分量每批按一阶、二阶矩投影，故多批后验与KG仍为近似；来源结构/通用模型的四个组合由联合证据更新权重。

四项新增测试对照原始高斯批次似然，覆盖相关局部更新、跨策略信息传播、组合权重和小样本方差；五项物理风险回归检查通过。来源拟合、两臂标签及预算均沿用U1。八个已打开开发任务的24格完整前缀重放，没有新增episode、观测、验证或服务器任务。

联合版本相对U1独立更新的平均预测log score仅高0.00131，4任务提高、4任务下降；g标签RMSE由0.11711变为0.11755，eta由0.55411变为0.55698。旧U1指标复现，积分相对误差最大1.62e−10。此次重放约16.2 CPU秒。

严重早期失败为95431/candidate33：预测验证通过率0.90951，实际5.02e−21。该候选已有付费观测；g后验−0.49509对真值−0.30050，eta后验−3.08782对真值−2.96588。仅替换g均值的诊断通过率降到0.15146，仅替换eta均值仍为0.84832。均值偏差是本例的主要原因，联合似然没有消除被选择点的过度乐观判断。替换真值只用于定位误差来源，不是可部署的修复。

结论：联合观测接口已完成，端到端校准尚未完成。保留本次正负结果，不据24点收益提高宣布少目标模拟目标达成，也不扩大服务器矩阵。下一步复用已验证的原始收费函数类与来源余项选择，把其接入统一正交模型，先做来源留一及相同八点前缀比较，定位现有均值结构与逐策略余项的影响。
