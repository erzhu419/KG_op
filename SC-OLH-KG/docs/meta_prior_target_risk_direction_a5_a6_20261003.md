# A5/A6：从目标观测学习风险方向（2026-10-03）

两步均完成，均不推广，不做推荐回放。每步复用全部 160 条旧路径，在 8/24 批前缀得到 320 个候选分组验证结果；源 meta-prior 与 f/g 模型保留。没有服务器任务、新拉取、搜索、KG 或随机验证。

A5 在训练候选上用边际似然，从 68 个公开函数中硬选一个残差方向及尺度。A6 保留同一单方向修正族，增加固定的零修正分支、源尺度指数先验，对方向、尺度和原源先验分量进行概率平均。两者均把重复候选的全部观测一起留出；真实支持只用于 A5 拟合后的诊断。

以下是结构先验在 24 批下的每批留出 log score 增量，越大越好，括号为未校正多组比较的配对种子 bootstrap 95% 区间。

**瓶颈判断：** A5 的训练拟合收益不能稳定泛化：24 批的全部训练折都选了非零修正，8 批下五类结构先验任务均下降。概率平均与先验正则化大幅缓解损失，但 A6 在共享结构、三头独立结构仍各有 15/16 种子下降，故未达到推广条件。

只解决“哪个单函数”还不够。high-frequency/60 的 A5 留出折在 19 折中有 12 折选中一个真实风险函数，整条路径仍下降 0.66925；A6 将损失降到 0.09242，仍未消除。这个例子支持测试同时更新多个风险函数；它尚不能证明模型容量是唯一原因。

下一步固定为源先验保留的联合风险更新：在 A6 中加入两个残差函数同时作用的分支，仍对方向和尺度平均，而不是硬选最优函数对。总残差方差的源尺度保持一致。先测一条路径的实际 CPU 成本，再在本地 0.25 CPU 小时上限内验证旧 cohort；见 [`A7 plan`](../performance/meta_prior_target_risk_joint_plan.json)。本轮未运行 A7。

**局限：** A6 同时引入先验正则化与不确定性平均，不能把改善全归因于平均操作。两个控制采用各自旧查询路径，不能把分数增量差异单独归因于 ARD。A3-A6 是同一开发 cohort 上的迭代诊断，没有独立确认、推荐收益或闭环搜索证据；这些结果也不能证明 source meta-prior 主线失败。

A5/A6 分别用 23.04/9.35 CPU 秒，单线程、峰值约 129 MB；六项测试通过，覆盖稠密似然对照、候选留出、秩一选择及完整概率混合。A6 在每组修正后验质量最大的折和四个原失败路径的最差折上比较 48/96/144 点求积：最大 48→144 点 joint log score 差为 2.31e−5，通过 1e−4 容差；该检查另用 0.78 CPU 秒。
