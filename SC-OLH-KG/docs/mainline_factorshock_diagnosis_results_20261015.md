# FactorShock固定轨迹诊断

结构prior确实改善了部分未采样策略的风险均值，但跨策略噪声更新破坏了终端排序；同源GP还存在更早的来源均值适应失败。两者不能用同一个风险均值补丁解释或修复。

复用上一轮d1000、seed80的三条13次观测轨迹与冻结来源模型，在共同18点上回放。[协议](../performance/manifests/mainline_factorshock_diagnosis_v1.json)／[分解结果](../paper_artifacts/mainline_factorshock_diagnosis_v1/decomposition.json)。表内均为池索引，0真实安全，4／5／9／16均不可行：

| 固定原查询路径后的终端解释 | 同源GP | 结构后端 |
|---|---:|---:|
| 原完整传播 | 4 | 16 |
| A：从来源先验起，每点只读自身raw | 9 | 0 |
| B：共同初始化10次后关闭跨点更新 | 5 | 0 |
| 保持完整均值／不确定性，仅换成A的噪声 | 4 | 0 |
| 同一13条raw交给旧后端及旧终端解释 | 0 | 0 |

结构后端的安全点0仅自身观测后，风险均值−0.08173、噪声标准差0.03673，接近真值−0.08438／0.03111；完整传播后变成−0.03153／0.23951，噪声方差约是真值59倍。查询16时，点0噪声标准差从0.11050跳至0.49044，主荐随即从0变成16。最终所有已观测点都不满足后验可行阈值，系统选择估计违约概率最低者；点16较大的认知不确定性使其标准化风险3.212低于点0的6.235，尽管其预测机会约束余量更差。

GP点0只读自身raw仍预测均值+0.31362，来源偏差已被吸收到噪声中。点4自身raw本可得到均值0.35268／噪声标准差0.05654，完整传播却退成0.06575／0.37330。替换真实风险均值能恢复选0，仅替换真实噪声不能；结构后端则相反，仅改均值仍选16，改噪声或统一认知不确定性尺度可恢复选0。

传播也有正确部分：在各臂固定的5个始终未采样点上，初始化→最终的风险均值MSE，结构从0.95343降至0.33715，GP从0.14579降至0.09764。结构最后一次查询还将点16的均值从0.07317纠正至0.53402。问题是这种均值改善尚未转化为正确推荐；各臂诊断点不同，MSE大小不作横向比较。

[来源检查](../paper_artifacts/mainline_factorshock_diagnosis_v1/source_geometry.json)未发现d1000→50网格转换遗漏。新振荡策略确实超出来源风险表示支持，但GP坏主荐4的公共均值坐标与来源点完全重合，仍发生跨任务响应失配。结构模型约全部来源质量落在两个joint谱身份，公共线性补充身份权重约3e−52；主导身份的7维任务系数协方差只有rank1，因为这里只含两个来源家庭。

下一步固定一个“查询与均值继续耦合、终端噪声只读本点raw”的对照，保留旧完整管线及同源GP参照，在新种子上沿用相同预算和终验。已有轨迹中的噪声分离已能恢复结构模型选0；下一轮检验它是否保留未采样预测改善并产生真实决策收益。

局限：这是单个已打开案例的固定路径诊断，替换后动作未经新增独立终验，不是替代算法收益。旧后端使用自身专家权重及混合概率，新后端保留Gaussian矩终端，比较不只涉及prior。替换旧认知方差时，CDF全部舍入为1导致平局，相关动作不能作为机制证据；原完整模型主荐不受该平局影响。只关闭噪声传播也尚未使结构模型将点0判为后验可行。

[完成账](../paper_artifacts/mainline_factorshock_diagnosis_v1/completion.json)：新增仿真／终验／拟合／下载均0；18点一次评分共54次解析truth函数调用，记录计算22.51 CPU秒。两臂最终动作与原保存值一致；一次1.07e−14混合求和差触发的过严相等断言及重跑耗时均保留，模型未改。
