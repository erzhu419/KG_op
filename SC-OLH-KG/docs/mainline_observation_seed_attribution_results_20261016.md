# 两组观测流的传播到部署归因

跨策略初始化传播确实带来了新策略部署收益。其相对逐点对照的质量优势中，**74.20%来自超越最优初始化的新策略，25.80%来自避免初始化退步**。[全量归因](../paper_artifacts/mainline_observation_seed_attribution_v1/summary.json)覆盖24个任务—观测流、全部9臂216终端格；[216次查询](../paper_artifacts/mainline_observation_seed_attribution_v1/query_diagnosis.json)精确重建，最大评分误差0。

AFTER两流各部署3个有真实改善的动态生成策略，共覆盖4个几何；POINT均为0。动态部署的平均正增量为+0.0000903815，共享邻域部署为+0.0009522637，主要质量仍来自共享邻域。AFTER未部署的7个好策略中，2个优于已获证部署、4个更差、1个因未获证而无此比较。不能将全部遗漏或全部动态部署次数视为额外质量。

两个关键机制已接通。**2113两流**中，仅把AFTER的风险均值替入POINT就能恢复首次查询57。第二流FULL前两次同查57，第三次因风险竞争集合变化改查41；57仍可行且目标排名第二。随后41终验失败、较差initial3获证，终端停在第三位57之前。**2111第二流**中，AFTER的25始终风险合格，因目标竞争未被查；POINT始终将25排除。同AFTER历史的native终端恢复34的证书，但34低于最优initial，恢复证书没有创造新质量。槽位、预算与验证随机流同时变化，未单独识别样本量作用。

以每份历史中最佳已观测可行新点定义机会H，未兑现量U＝H−P，则G＝H−U−L。FULL相对AFTER的H多+0.0001162003，U也多+0.0001608052，再加2113退步，形成负结果；持续传播带来的搜索机会没有稳定兑现。AFTER相对POINT则多找到+0.0011379820机会，扣除多出的+0.0001029846未兑现量，得到+0.0010349974新策略收益。
