# 官方 HyperBO 单任务完整闭环

协议在新目标观测前冻结：来源档案使用独立确认批次的4个来源规律，目标规律固定为95025，目标噪声种子为96025，成本预算为1.1885871647，8个共同初始点、24个付费搜索点、928次独立验证，总目标预算1216。两臂为当前 source billing 联合后验和官方 HyperBO；前者使用物理 factor-family 风险后验与相关 Gaussian KG，后者使用官方三头标量 HyperBO 后验和独立头 KG 扩展。

完整闭环实际运行成功。两臂各完成24个搜索点和928次验证，均无错误认证；配对观测缓存后实际模拟调用2324，分配调用为2432。source billing 的初始和最终推荐均为策略81，HyperBO 从初始策略51变为最终策略50。95025 在96个候选中没有真实可行策略，两个最终预计验证收益分别约为 `1.89e-151` 和 `1.64e-229`，验证均未通过。

这个结果完成了官方成熟方法的端到端信息合同：来源训练、目标后验、搜索协方差、独立验证和事后真值记录均已接通。它同时保留了负证据：在没有可行策略的任务上，推荐差异不能解释为方法优劣，也不能把无错误认证写成部署成功。当前 Inventory 生成器仍没有提供适合比较最终决策收益的任务层。
