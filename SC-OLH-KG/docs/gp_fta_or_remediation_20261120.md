## 执行记录与完成后的投稿判断

U3 是共享面板上的版本复测。原代码快照与三份 U3 摘要的执行指纹一致。主面板和原尾组合计 7,544 格，获证 6,144 格，弃权 1,400 格。同律复核有记录的 1,624 格里，违规率点估计均未超 5%。其中 279 格来自 GP-FTA 两臂。独立电网审计在两臂发现 28 格明确不安全，截尾和原尾分别为 10 与 18。Live SUMO 中 KG 获证 8/16，独立审计判 3 格明确安全、5 格不确定。PublicPsi-TargetGP-TS 已列入四族主表，在库存和交通 DES 的损失均低于冻结 KG。表内另列实际模拟调用，让相同搜索步数和实际费用可以分别比较。

杂乱档案的历史搜索作业清单在本地截断。保留旧件，从冻结 U3 描述器及原封存参数重建完整清单。2,108 个任务与账本逐格匹配，重建文件的前 1,097,728 字节与截断件完全一致。复现导出另核对 18 份历史 CSV 的摘要绑定。对本地以 LF 保存的文件，在内存转回原写入器的 CRLF 后一致，账本文件字节保留。

KG 幻想功率现按正权重规则校准到当前均值。原排序反例，无信息查询从 0.01944 变为 0，有信息查询约为 0.00489。终验逐分支测试覆盖三槽守门、首过即停、双获证后的目标样本均值择优、并列和短名单误差分配。论文的安全界针对有效验证律下的错误获证返回。标量 SURE 和固定幻想模型结论分别写明适用条件。所有 14 项 Python 测试通过。

独立包的锁定 Python 环境可重算六表及三图，并可加载 OPSD 和 SUMO 1.22.0 输入。SUMO 显式指定 libsumo 时优先选择已安装的锁定引擎。引擎加载检查覆盖 44 维、21 个信号和 4,283 条行程，无模拟调用。论文 PDF 28 页，表在参考文献后，主表查验无裁切，编译无未定义引用。保留模板在小字号数学上的字体回退提示。

Lean 4.31.0 使用锁定的第三方依赖缓存重新编译 6 个项目模块，13 项公理检查通过，项目 `.olean` 复用为零。首次 Lake 运行因节点没有 Git 失败，并通过缓存目录链接误删了 Mathlib 的缓存展开目录。现已从原有 2,435 个压缩缓存对象及锁定版本源码恢复。四个调度尝试均收录，包含缺少系统 Python 的启动失败、解包参数失败及成功恢复，自动重派为零。已测构建和恢复总计 **84.831 CPU 秒**，末次证明编译占 40.466 CPU 秒。启动控制开销无独立计量。公开 Lake 联网拉取路径未实际验收。 [Lean 回执](../paper_artifacts/v2_or_remediation_lean_receipt.json)

最终 ZIP 从独立目录验收，可重算论文所用六张表和三张图并重编 PDF。

### 完整复现与投稿边界

独立包支持论文表图、确定性接口和证明的复验。历史端到端重放还需要保存的候选和部署策略向量与评估器输入。精确恢复搜索另需来源账本和拟合产物，或另行重建它们。历史 Live SUMO 的 Python 指纹未覆盖外部适配器和实际运行引擎。现有封存账本记录已完成调用，缺失调度回执不能据此推定为零支出。复核日志、费用和已知失败全部保留，原余量无重置，新增正式实验调用为零。

当前建议暂缓 OR 正式提交。修正 KG 已达确定性正确性验收，新的决策表现尚缺独立任务上的证据。后续实验应冻结修正版、同表示强对照及预算，配对比较 GP-FTA-TS 和 PublicPsi-TargetGP-TS，报告实际调用与审计结果。对历史运行的可复现范围，应补齐缺失输入，或在提交材料中具体说明可提供的证据、边界及适用的豁免。公开发布前确认数据和模板的再分发权利及作者信息。这些工作本轮均需保留原实验身份。 [OR 代码与数据政策](https://pubsonline.informs.org/page/opre/code-and-data-disclosure-policy) · [OR 投稿规范](https://pubsonline.informs.org/page/opre/submission-guidelines)
