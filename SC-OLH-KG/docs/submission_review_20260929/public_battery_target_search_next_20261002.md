# 固定预算目标搜索与验证重放

30/30 配对试验已完成：三季 × 五个算法重复 × 两个冻结设计。每次 13 个不同库候选，各抽一个窗口；成功样本按已定义成本排序，失败样本成本保持 null、按评估顺序排在成功样本后。固定三个短名单候选，每个用独立随机流有放回抽样 80 次，全部成功且单侧 Clopper–Pearson 下界达到 0.95 才认证，首次认证后结束。此处的独立性来自随机抽样流，窗口集合仍为已观察开发人口。

| 设计 | 认证 / 15 | 假认证 | 代表性目标查询 |
| --- | ---: | ---: | ---: |
| source 首点 + 相同结构几何 | 15 | 0 | 1,395 |
| 纯结构 medoid + 相同结构几何 | 9 | 0 | 2,355 |

三季认证分别为 source 5/5、5/5、5/5，对照 5/5、3/5、1/5。所有认证部署均为常数联合候选，source 首点 0.75/0.75 被部署 12/15 次；不能把结果解释为函数策略或完整 atlas 收益。

缓存重放没有新增控制器仿真；上述 3,750 次是重放所代表的查询预算，重复抽到的窗口仍计作独立随机抽样。实际 source 档案已付出 44,968 次控制器评估。五个重复按每季取平均，再累计三个季节任务：source 代表性目标查询 279、预期认证 3；对照 471、预期认证 1.8。计入来源后每个预期认证约 15,082 次查询，对照约 262 次。三个任务没有建立来源成本回收优势；该比较是查询次数，不是实际运行时或业务费用。

三项新增测试通过：失败成本不充当廉价目标、随机流分离与有放回记录、成功认证/失败弃权及预算。冻结设计与原库、窗口、控制器、可靠性门槛均未修改。

## 局限与下一步

这是已观察 2024 人口上的回顾性有限库搜索适配：随机排列续点，非原连续 Sobol 或贝叶斯优化。认证只对应固定均匀窗口分布，不能作独立年份或真实业务认证。失败完整目标仍未定义，完整增强 atlas 未接入。source 对比保持 HOLD，2025 封存；不据此次结果改种子、源首点或认证门槛。

下一步先冻结简单常数基线、等成本预算及独立确认的目标规则，再决定是否有充分理由进入封存期。保留认证率差与来源成本负结果，不继续用开发数据反复寻找有利设置。
