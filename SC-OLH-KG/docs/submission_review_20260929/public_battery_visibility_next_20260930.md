# 首次失效信息追溯与下一步

四月 **4,745** 个固定策略—窗口组合完整复现 V3 的成功标记和首次失效分钟。**4,720** 次（99.47%）在对应计划提交时预测路径安全，后来收到的指令改变了执行路径；另 **25** 次提交时的前一小时固定计划已经预计越界。没有归入“新提交段已知越界”的失效，没有追溯未决项。64 条库内候选分别为 4,647/25 次；50% 参考策略的 73 次失效全部属于后来指令改变路径。

25 次已知越界均涉及实际失效的单元，但发生在已固定的待执行小时，不能归咎于当次新计划。后来指令类别包含全部 663 次共享功率失效。因此下一步修正因果库存与功率备用；单独增加新计划的已知路径检查不足以处理本次瓶颈。

V4 已固定在 `performance/manifests/public_battery_unit_reserve_development_v4_20260930.json`：用提交前 90 分钟已执行 BOA 的双向能量建立每单元目标库存区间，并按另一单元近期 BOA 峰值留出共享功率。90 分钟对应原有 60 分钟提前量加 30 分钟交付段。原 64 条候选、三个季节、73 个窗口、容量、共同初始库存、效率与 95% 门槛保持不变；下一步实现并串行完成 14,673 次评估，保留与 V3 的配对结果。尚未运行 V4，source 比较继续暂缓。

后续：V4 现已完成，可行库内候选为 0/1/25 条，仍无跨季节共同可行候选；已固定两项备用的组件比较，见 `public_battery_reserves_next_20260930.md`。

原七项控制测试及三项追溯测试通过。首次运行完成分类后遇到示例 JSON 的整数序列化错误，修正后完整重跑，合计 9,490 次诊断窗口评估；新增数据请求、算法优化器及认证调用均为零，2025 未读取。

局限：这些重叠窗口的策略组合不是独立事件；分类只追溯实际首次失效前缀，没有证明所有提交路径安全或在线问题无解。经验备用不能保证未来指令受过去轨迹约束，也没有实际电站或 source 收益结论。

结果：`paper_artifacts/public_battery_unit_failure_visibility_v1_20260930/summary.json`、`failures.csv`、`examples.json`。复算：`python3 performance/inspect_public_battery_visibility.py`。
