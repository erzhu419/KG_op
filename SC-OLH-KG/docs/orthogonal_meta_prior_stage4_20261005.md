# 公开收费偏移与系数联动：保留全字典撤回通道改善早期决策

已把公开响应偏移放入`InventoryPlan.mean_offsets`，模拟器的响应定义不变。四个收费函数沿用上一阶段的来源选择。本阶段研究截距和价格系数的联动，不重新宣称学得四个函数。若`Z=(q-mu)/s`，则`H=offset+(Z+mu/s)beta`，因此中心化截距满足`b=offset+(mu/s)beta`，不能再独立变化。

来源价格二阶矩在扣除各场景公开偏移后估计；余项仍由来源规律留一在0与0.02间选择。目标非截距均值为零，未知价格仅来自付费标签。完整协方差、旧来源协方差和同支持汇总尺度三个版本均保持该联动；汇总对照匹配系数方差总量，eta先验和联合批次更新、验证效用、KG不变。这三臂把后备模型也限定为四个收费函数，因此另加严格归因臂：旧来源系数协方差、原72函数后备模型都保留，只改变来源分量的截距联动。该臂在三臂开发重放后添加，属于事后机制归因，不是预先冻结的确认。最终来源拟合和四臂重放约17.7 CPU秒，无新增实验观测、验证调用或服务器任务。

3项新测试验证实际库存公开几何上的函数协方差、正交运输、付费后截距联动、可变场景偏移消除和汇总尺度匹配；4项原模拟检查通过。事后评分复现旧奖励的误差为零。

来源外层留一：f RMSE由0.04113降至0.03914，g由0.08272微降至0.08253。f工作预测log density由1.758升至1.797，g由1.045降至1.023，故来源结果并非全面改善；全部外层及全来源拟合仍选零余项。相同目标路径上的g RMSE由0.10151降至0.07930，联合log score由0.36937升至0.41515，eta预测几乎不变。

保留原后备模型的归因臂在8点后相对上一收费模型平均+0.17249，2胜5平1负，开发配对bootstrap区间[−0.00002,0.39761]；改善集中于95425和95431。对旧72维控制平均+0.09936，区间[−0.00014,0.29821]，不能称为跨任务显著优势。95431在8点时改荐14，实际通过率0.99729、预计收益0.79524，预测通过率0.90205；95425也避免了上一阶段的退步。24点所有联动臂推荐一致，仍比旧72维控制低0.00099。

将后备支持缩成相同四函数的三臂8点后收益均为0.75568，24点均为0.86174；它们推荐完全相同，来源协方差重估没有额外推荐收益。相对保留原后备模型的归因臂，8点平均低0.09326，主要由95431产生。这组数据支持保留原有全字典撤回通道，不能将四函数汇总对照直接替代它。来源与同支持汇总版本各在1/8任务改变下一KG探测点，但探测未执行。

四函数后备版本中，95431仍严重误判：从候选33转至67，预测通过率0.93181，实际0.00176，预计收益仅0.00140。g后验−0.46769对真值−0.34431，偏差−3.16个标准差；eta偏差仅−0.31个标准差。仅替换g均值的诊断通过率降为0.39985，仅替换eta仍为0.89115。公开联动修复应与完整撤回通道一起检验，不能据单个窄模型的失败否定联动，也不能据归因臂成功宣布全面校准完成。

已进一步用公开收费量反解固定Gaussian后验的价格分布，不读取真实目标价格。95431的缺货价格均值0.07331，95%边际区间[−0.22546,0.37208]，低于公开下界0.4；订货价格均值0.92668高于上界0.9。95425也有三个价格均值越界，含负的持有价格。96候选上的均值重构误差最多1.25e−11，说明这些价格确实对应当前后验函数。公开价格域尚未进入模型，是下一项具体可修复的模型遗漏；不能通过裁剪最终效用来代替系数后验修正。

局限：本阶段仍是已打开开发任务的固定路径重放，非新的搜索、独立确认或认证；误判案例由事后真值评分选择，价格解码本身未使用真实价格。归因臂是事后添加的开发分析，置信区间跨零，收益集中于少数失败任务。来源对比沿用四场景8点，目标为单场景8点。风险因子恢复和稳定独立的meta-prior决策优势仍未建立。

下一步保留原全字典撤回通道，同时给物理收费结构与同信息对照加入公开价格可行域，先来源验证，再重放相同目标标签；保持预算、机会约束和开发规律不变。检验价格约束能否纠正窄模型的均值过度乐观及其对完整混合的影响，再判断来源先验与KG是否有新增价值，不据本阶段账单修复改写原始风险结构学习主张。
