# 一次查询后的正式提名对照

复用第二轮已恢复的 24 个初始化状态。每族 12 个用原注册索引和首流。每个状态的查询池固定为原算法产生的 160 个物理策略。补充样本为每族索引 0、12 的四个末轮前状态，恢复与验收单列。[晚期状态协议](gp_fta_eligible_late_protocol_20261120.md)

一个备选查询在同一策略上给出两次观测。共同工作律使用相互独立的目标和约束高斯头，分别生成批均值与正交差分。用两条预测原始观测计算均值、批内方差和超标计数，执行真实的记录聚合、HVD 更新及正式提名。只有已观测集和这次查询可进入终验。记录聚合按六位键，正式名单按五位键。实际名单长度与守门角色决定收费、错误率分配及终验分支。两种计值共享每个幻想的名单，首槽使用原分配，首槽失败则回到现状。两种计值在工作律下均保留有符号收益。用于评价的现状代价取缓存的共同参考，正式提名仍采用原始随观测更新的参考。

主有限幻想律为 64 个四维 scrambled Sobol 节点，种子 78463511。嵌套 32 节点及固定第二种子 78463529 衡量有限预测粒度的敏感性。终验结合 Beta 阈值变换的 24/48 阶边际积分及 512/2048 节点的两次独立联合积分，种子 4157201、4157213。用 512 个等质量边际分位区间和 Fréchet 界给每个查询的该工作律计值上下界。唯一保留时直接确定有限预测下的全树最优，仍有多个时对保留者及首槽首选精算。分别报告首选差异、数值一致性、合法名单全树增益及共同更新、筛选、联合积分的工作者计时。

仅读复用原前缀、来源先验和模拟器配置。计算由六节点 CPU 队列调度，保留所有完成及失败费用。回放晚期状态的搜索调用与两个评分的零调用区分。各阶段留档且无自动重派。
