# Terminology and Claim Ledger

## One-Sentence Argument

Historical simulations can score a public finite structural library for a new
ordered-profile problem, but the benefit is conditional on source-target
profile alignment and should be evaluated against generic structure, full cost,
and independent terminal verification.

## Canonical Terminology

| Term | Meaning |
|---|---|
| ordered policy profile | A bounded function on `[0,1]` observed on a declared ordered grid |
| shared structural library | The deterministic 64-profile outcome-free library |
| source-scored structural initial design | The ten profiles selected from the shared library using replicated source ranks and farthest-first coverage |
| generic DCT maximin | Outcome-free structured control using the same library and cosine coordinate |
| source archive | Two source tasks by 64 profiles by three replications, or 384 calls, in the randomized primary study |
| source retrieval | Upstream selection of related historical tasks; exogenous and outside the claimed method |
| augmented selection coordinate | `eta=(z,r_g,r_f)`, used by source-scored farthest-first selection |
| structural transfer coordinate | `z`, the projected profile coordinate in which target coverage is asserted |
| target search calls | Calls used to initialize or adapt on the held-out target |
| verification calls | Fresh terminal calls that never update search |
| equal preverification cost | Source plus search cost is matched before verification |
| independent certificate | Acceptance by the frozen-shortlist exact-binomial verifier |
| false certificate | A certified deployment that is infeasible under postdecision benchmark truth |
| penalized loss | Unconditional endpoint that retains infeasible runs in the denominator |
| calls per certified deployment | Amortized source, search, and verification calls divided by the observed certificate-success probability; descriptive rather than a safety guarantee |
| nominal grid dimension | Number of implementation nodes, not intrinsic profile rank |
| registered task law | Frozen randomized distribution over eight profile regimes |
| native transfer pipeline | A comparator retaining its own prior, initialization, and acquisition logic |
| Energy V3 | Region-held-out negative external control; not a source-learning success |

## Final Method Identity

```text
public structural profile library
  -> source outcome ranks
  -> source-scored ten-profile initial design
  -> replaceable target backend
  -> independent terminal verifier
```

The novel object is the source-scored initial design. Canonical SAASBO,
functional SCBO, KG, posterior sampling, and transfer optimizers are backends or
comparators. Cumulative factor-HVD is a secondary calibration diagnostic.

## Bounded Claims

1. On the registered randomized ordered-profile task law, source scoring
   improves aggregate feasible coverage, certified deployment, and penalized
   loss over generic DCT maximin and the other source-free controls.
2. The advantage is not universal: registered adverse regimes and Energy V3
   contain reversals.
3. Cross-grid consistency supports policy discretization refinement; it does
   not establish generic optimization in 10,000 unrelated variables.
4. The 384-call source archive is an amortized multi-target investment. It is
   not the best one-target equal-preverification-cost method.
5. Independent verification gives a finite familywise false-deployment bound
   under the declared iid replication law, but has low power near the chance
   threshold.
6. Lean verifies the finite implications; source-target alignment, task-law
   membership, and iid simulator semantics remain empirical assumptions.
7. The randomized study contains 160 independent latent task seeds crossed
   with three resolutions. The resulting 480 paired cells are descriptive and
   are not treated as independent task draws.

## Prohibited Claims

- The method solves arbitrary high-dimensional black-box problems.
- Ten target calls are the total simulation cost.
- Source learning is universally better than generic structural design.
- Energy validates a source-learning advantage.
- KG or HVD is the source of the primary optimization gain.
- Three legacy domains establish transfer to a population of domains.
- Zero observed false certificates proves zero deployment risk.
- A formalized conditional theorem proves its assumptions in real systems.
- The method discovers which historical source tasks are related to the target.
- The augmented source-rank coordinate is itself a target semantic coordinate.

## Evidence Priority

1. Randomized profile primary and adverse-regime matrices.
2. Schema, source-budget, and equal-preverification-cost controls.
3. Energy V3 negative external control.
4. Verifier power and temporal-scope audits.
5. Native transfer pipelines and functional SCBO.
6. HVD calibration-only appendix.
