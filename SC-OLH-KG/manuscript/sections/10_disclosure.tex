\section{Code and Data Disclosure}\label{sec:code-data}

All synthetic instances are generated by deterministic code with the declared
seeds. The external electricity-reserve study uses the public Open Power
System Data time-series release cited in Section~\ref{sec:experiments}. An
anonymous reproducibility package contains the source code, frozen manifests,
compact audited artifacts, and build instructions needed to reproduce the
reported tables and figures. Raw optimization checkpoints are not required
for reproduction. A persistent public identifier will replace the anonymous
archive location upon acceptance.
