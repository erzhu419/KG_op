# Data and code availability

The fixed review attachment contains the current mainline Python sources,
the locked current Lean source closure, compact Stage85/93 registered cell
records, recomputed statistical outputs, frozen source models, source
archive/design records, one preselected case and acceptance receipts. The
attachment is the review access mechanism; no DOI or public archival accession
has yet been assigned. The assembled snapshot is identified by its manifest.

All three task families in this attachment are generated synthetic benchmarks.
`data/cells.json.gz` preserves all 5,760 registered cells, missing values,
failure states, geometry/stream/arm pairing keys, recorded calls and source
references. `data/statistics.json.gz` and `statistics.py` provide the corresponding
statistical output and a cell-based reconstruction route. The original two
cohorts and the reused Stage103 analyses retain separate identities.

The `assets/` directory supplies the frozen source/native priors for each
held-out family and their separately identified source-permuted counterparts.
The real-family `archive.json` and `design.json` retain source observations and
the source-only initial design. The case directory supplies the resolved
configuration, ten initial observations and fixed shared-neighbor bank. A new
small-case execution writes its raw target and independent-verification calls,
frozen terminal input, returned decisions and attempt receipt.

Full historical search checkpoints and large target trajectories remain in the
original research archive and are not required for the supplied cell-based
statistical replay. Historical references in cell records describe provenance;
they do not imply that every historical referenced server file is included in
the review attachment. Full end-to-end regeneration of every historic cohort
is distinct from the supplied statistical replay and one real acceptance case.

Self-owned code included in this attachment is distributed under MIT and
generated benchmark records and model assets under CC BY 4.0. Third-party
components keep their own terms. See `THIRD_PARTY.md`.

## Known limitations

The actual historical scientific execution commit is not established by the
retained receipts; the reviewed base commit identifies a delivery snapshot.
Historical unmeasured CPU, peak memory and monetary charges remain unknown.
Source numerical warnings, all 67 failed cells, failed acceptance attempts and
recovery costs remain recorded. No synthetic outcome is imputed from a failed
run, and no existing budget reserve is reset.

The corresponding author should replace the review-attachment access sentence
with the final repository/accession on public archival release and confirm the
rights/disclosure facts in `AUTHOR_DISCLOSURE.md` before journal submission.
