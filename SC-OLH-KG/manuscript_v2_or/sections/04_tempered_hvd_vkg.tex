\section{Gate-Power-Aligned Functional Transfer (\texttt{GP-FTA}) and Cascade Verification}\label{sec:model}\label{sec:vkg}

Within our unified \emph{Gate-Power-Aligned Functional Transfer} (\textbf{GP-FTA}) architecture, a shared semiparametric posterior supports two complementary online acquisition policies: \textbf{GP-FTA-KG} (one-step rank-one lookahead) and \textbf{GP-FTA-TS} (joint posterior Thompson sampling).

\subsection{Within-Policy HVD Estimation and Plug-in Predictive Release}

When transferring to a shifted target task $t$ where $g_t(x) = \tilde{\phi}(x)^\top \mu_{0,g} + \Delta_g(x)$, conditioning variance parameters on prior residuals $(Y_{t,g,\ell}(x) - \tilde{\phi}(x)^\top\mu_{0,g})^2$ leaks epistemic shift $\Delta_g(x)^2$ directly into aleatoric noise estimates, and persistent post-hoc uncertainty buffers can affect nominations. GP-FTA separates the dispersion statistic from the mean model and includes pruned-mode uncertainty in the GP covariance.

\paragraph{1. Within-policy dispersion.}
Given $n$ unique evaluated target policies $\{x_1,\dots,x_n\}$ with replicated subset $\mathcal{I}_{\mathrm{rep}} = \{i : r_i \ge 2\}$ and total degrees of freedom $D_n = \sum_{i \in \mathcal{I}_{\mathrm{rep}}} (r_i - 1)$, we estimate $\hat{\gamma}_{t,c} \in \R_+^{14}$ from centered within-policy sums of squares:
\begin{equation}\label{eq:hvd_map}
  \hat{\gamma}_{t,c} = \arg\min_{\gamma \ge 0} \;
  \sum_{i \in \mathcal{I}_{\mathrm{rep}}} (r_i - 1)\left(\frac{S_{t,c,i}^2}{r_i - 1} - u_{\mathrm{HVD}}(x_i)^\top \gamma\right)^2
  + \lambda_{n,\mathrm{HVD}} \|\gamma - \gamma_{0,c}\|_2^2,
\end{equation}
where $\lambda_{n,\mathrm{HVD}} = \min\{3,\, 0.5 + 2.5 N_{\mathrm{src}}^{\mathrm{rep}}/36\} / (1 + 0.10 D_n)$ decays smoothly with target degrees of freedom $D_n$ (and switches to target-only regularization once the prior is released). The intercept and variance-envelope adjustments use the empirical median target variance $\hat{m}_{v,c} = \operatorname{med}_{i \in \mathcal{I}_{\mathrm{rep}}}(S_{t,c,i}^2/(r_i - 1))$. The code also uses absolute numerical floors. The resulting prediction uses $\hat{v}_{n,c}(x) = \max\{u_{\mathrm{HVD}}(x)^\top \hat{\gamma}_{t,c},\, 10^{-10}\}$ and $\hat{v}_{n,g}^{\mathrm{UCB}}(x) = \hat{v}_{n,g}(x)\big(1 + 0.35 / \sqrt{\max\{1, D_n\}}\big) + \min\{\underline{v}_{0,g},\, 0.20\,\hat{m}_{v,g}\}$.

Centering removes an additive policy mean exactly. Unbiasedness of $S_{t,c,i}^2/(r_i-1)$ holds for fixed-size IID policy samples, including a fresh batch with size chosen before its outcomes. Data-dependent revisits can bias the pooled statistic. Section~\ref{sec:theory} states the distinction, and the matched experiment reports a diagnostic comparing fixed-batch and pooled variance estimates against independent audits.

\paragraph{2. Pruned-mode conditioning and adaptive release.}
Setting empirical target scale $\hat{s}_{y,c}^2 = \max\{\widehat{\Var}(\bar{Y}_{t,c,1:n}),\, \operatorname{med}(\hat{v}_{n,c,1:n}/r_{1:n}),\, 10^{-8}\}$, each head $c \in \{f, g\}$ evaluates two candidate branches using the analytic fixed-parameter leave-one-out negative log predictive density \citep[\texttt{LOO-PLL}, Eq.~5.12 of][]{rasmussen2006gaussian}:
\begin{equation}\label{eq:loo_pll}
  \mathcal{J}_{\mathrm{LOO}}(K_c, m_c) \coloneqq \frac{1}{2}\sum_{i=1}^n \left(\frac{[(K_c^{-1}(y_c - m_c))_i]^2}{(K_c^{-1})_{ii}} - \log (K_c^{-1})_{ii}\right),
\end{equation}
The means, variance model and standardization entering this formula are fitted using the available target data. The release branch, for example, uses the full sample mean. Accordingly this is a plug-in score, rather than fold-by-fold refitting or evaluation on independent data.
\begin{itemize}
  \item \emph{Source-Anchored Tempered Branch ($\beta_c \in \{1.5, 1.0, 0.35\}$):} sets prior mean $m_{0,c}(x) = \tilde{\phi}(x)^\top \mu_{0,c}$ and conditions \emph{both} active covariance $\Sigma_{0,c}$ and pruned-subspace features $w_{\perp,c}(x)$ inside the GP kernel:
  \begin{equation}\label{eq:composite_kernel}
    K_{0,c}(x, x'; \vartheta_c) = \beta_c^{-1}\!\Big(\tilde{\phi}(x)^\top \Sigma_{0,c}\tilde{\phi}(x') + w_{\perp,c}(x)^\top w_{\perp,c}(x')\Big) + \tau_c^2 \tilde{\phi}(x)^\top\tilde{\phi}(x') + \sigma_{\perp,c}^2 k_{\nu=5/2}\!\big(\tilde{\psi}(x), \tilde{\psi}(x'); \ell_c\big),
  \end{equation}
  over $\tau_c^2 / \hat{s}_{y,c}^2 \in \{0, 0.08, 0.35\}$, $\sigma_{\perp,c}^2 / \hat{s}_{y,c}^2 \in \{0.03, 0.20, 0.75\}$, and $\ell_c \in \{0.45, 0.85, 1.45\}$, regularized by $0.08\sqrt{n}\big(|\log\beta_c| + 0.5\tau_c^2/\hat{s}_{y,c}^2 + 0.25\sigma_{\perp,c}^2/\hat{s}_{y,c}^2\big)$. At fixed covariance parameters, conditioning this component on observations reduces its posterior covariance. The algorithm may reselect parameters after each update.
  \item \emph{Penalized Target-Only Release Branch ($\beta_c = 0$, activated for $n \ge 10$):} replaces the source mean with $\bar{y}_{t,c}\mathbf{1}$, re-standardizes $\psi(x)$ on target observations $\tilde{\psi}_{\mathrm{tgt}}(x)$, searches $\tau_c^2/\hat{s}_{y,c}^2 \in \{0.15, 0.60, 1.50\}$ and $\sigma_{\perp,c}^2/\hat{s}_{y,c}^2 \in \{0.10, 0.50, 1.50\}$, and is selected whenever $\min_{\vartheta_{\mathrm{rel}}} \mathcal{J}_{\mathrm{LOO}}^{\mathrm{rel}} + \tfrac{1}{2}\log n < \min_{\vartheta_{\mathrm{src}}} \mathcal{J}_{\mathrm{LOO}}^{\mathrm{src}}$. When either head releases ($\beta_f = 0$ or $\beta_g = 0$), \textbf{GP-FTA} also disables source DCT template injection in subsequent candidate pools and uses target-only HVD regularization when there are at least four replicated policies. Hybrid initialization combines the public anchor with source templates and exploratory policies.
\end{itemize}

\subsection{Gate-power query rules and terminal verification}

For a policy with violation probability $p$, the binomial gate at slot~0 with $K_0 = \SlotZeroK$, $\delta_0 = \SlotZeroDelta$ and $\alpha=0.05$ permits at most one violation. Its pass probability at that $p$ is
\begin{equation}\label{eq:exact_gate_power}
 C_{K_0,1}(p) = (1-p)^{K_0}+K_0 p(1-p)^{K_0-1}.
\end{equation}
At $p=0.05$ this is $0.02206$. Search uses a model-based approximation to this probability. It applies $C_{K_0,1}$ to $P_n(x';Z)=\Phi((\mu_{n,g}(x')+s_{n,g}(x')Z)/\sqrt{\hat v_{n,g}^{\mathrm{UCB}}(x')})$, then averages over a Gaussian epistemic draw:
\begin{equation}\label{eq:post_gate_power}
 p_n^{\mathrm{gate}}(x') \approx \sum_{r=1}^9 \omega_r C_{K_0,1}\big(P_n(x';\zeta_r)\big).
\end{equation}
Here $s_{n,g}$ is the effective epistemic standard deviation for the gate calculation. The finite-sample CDF is exact conditional on $p$. The Gaussian mapping and plug-in noise estimate can misestimate $p$ when simulation outputs are non-Gaussian or poorly calibrated.

The reference $\hat J_n^{\mathrm{ref}}$ combines the available status-quo estimate with an offset proportional to the spread of candidate posterior means. With this reference held fixed within a query calculation, define $V_n(x')=(\hat J_n^{\mathrm{ref}}-\mu_{n,f}(x'))_+p_n^{\mathrm{gate}}(x')$. The frozen U3 lookahead screens up to 64 evaluation targets and computes
\begin{equation}\label{eq:bgpkg_acq}
 \left[\sum_{q=1}^{25}\varpi_q \max_{x'\in\mathcal{E}_n} V_{n+1}(x';x,z_{f,q},z_{g,q})
            -\max_{x'\in\mathcal{E}_n} V_n(x')\right]_+.
\end{equation}
It uses a product Gaussian rule for rank-one mean fantasies and a seven-node rule for the future gate integral, with fitted noise held fixed. The evaluation set may include unobserved policies. The score is a single-slot lookahead surrogate for search. Actual terminal eligibility and selection use the rule below. GP-FTA-TS instead samples objective and constraint mean paths using the fitted covariances and ranks candidate draws by their gate-weighted savings. It uses low-cost draws among candidates with high gate power when the positive-savings score provides no ranking, and a feasibility-oriented fallback when estimated gate powers are low.

\paragraph{Numerical version.}
The different quadrature rules in~\eqref{eq:post_gate_power} and~\eqref{eq:bgpkg_acq} can assign apparent value to an observation with zero innovation. The corrected implementation in the replication attachment uses a finite-rule calibration described in the Electronic Companion. All U3 tables refer to frozen run source \texttt{5965482dba30}. \paragraph{Nomination and executed terminal rule.}
The algorithm freezes up to three distinct evaluated candidates. It nominates a primary using a gate-weighted estimated saving against a proxy continuation cost. The continuation heuristic uses an empirically feasible incumbent and a conservative interior candidate. In particular, the incumbent uses pooled variance shrinkage toward $\hat v_{N,g}^{\mathrm{UCB}}$ and prefers zero observed violations. When the strict screen is empty it falls back to zero-violation candidates and then to a margin ordering. Duplication is resolved before verification, and the retained roles determine the executed branches.

If the frozen second slot has the incumbent-guard role, the first two slots receive fresh verification blocks. If exactly one passes, it is selected. If both pass, the smaller verification sample mean objective wins, with ties to the first. If both fail, a third slot is tested when present. Without the incumbent role in slot~1, slots are tested in order and the first pass is selected. Exhausting the available slots without a pass leads to abstention. Slot budgets and allocations are $(\SlotZeroK,\SlotOneK,\SlotTwoK)$ and $(\SlotZeroDelta,\SlotOneDelta,\SlotTwoDelta)$ for three slots. Shorter lists use the same initial budgets and redistribute the error level across the available slots. The reported experiments use exact binomial gates. The optional noncentral-$t$ gate requires the specified Gaussian law. Theorem~\ref{thm:vkg_safety} concerns unsafe certification. The objective comparison in the guard is a sample ranking rule.
